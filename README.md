# Blog API
## Description: 
Blog API is a simple blog web app with an API-only backend, and two different frontends used in accessing, editing, & publishing blog posts.
The aim of this project is to help me
- Build APIs,
- Add security features when buidling APIs 
- Set up seperate websites for frontend and backend
